Privacy policy

Last updated: 15 November 2026

Majesty Makeup Studio uses a private, self-hosted application to manage its own appointments. The application is used only by the studio owner and is not available to the public.

Google Calendar access

When the studio owner connects her own Google account, the application requests permission to see the list of her calendars and to create, update and delete events in the calendar she selects. It uses this access only to copy the studio's appointments into that calendar.

  • Events contain the event type, the customer's first name and last initial, the location, a booking reference, the number of people and the booking status.
  • The application does not read, store or analyse any other Google data.
  • Google data is never sold, shared with third parties, or used for advertising.
  • Access tokens are stored encrypted on the studio's own server and can be revoked at any time in the application or at myaccount.google.com/permissions.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Customer information

Customer details (such as name and phone number) are kept on the studio's private server only, for managing appointments, and are deleted on request where no legal retention obligation applies.
